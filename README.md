# personality-check

長所・短所を見つける自己理解チェック。`index.html` をブラウザで開くと利用できます。ビルドや外部ライブラリは不要です。

開始画面上部の「日本語 / English」で言語を選べます。40問、結果、面接の型、コピー・共有文が切り替わります。「もう一度チェックする / Start again」で言語選択に戻れます。再開始では回答とメモを消去し、選択言語は保持します（再読み込み時は日本語）。

## 内容の方針

- ビッグファイブの観点を参考にした独自の40問です。心理尺度としての信頼性・妥当性は検証していません。
- 結果は回答の傾向として示し、能力・適性・優劣や集団内の順位を推定しません。
- 各観点8問。逆転項目を反転して集計し、0〜2・3〜5・6〜8で表示を分けます。これは仮の表示ルールで、検証された境界値ではありません。
- 経験の振り返りを中心にし、短所から別の長所を自動的に推定しません。
- 回答・経験メモは保存しません。メモはコピー・共有・印刷の対象に含まれます。

### 英語対応

- 英訳は `index.html` 内の `EN` 辞書に集約。日本語の原文をキーとするため、原文を変更する際は辞書のキーも更新します。採点用の因子・逆転項目は両言語で共通です。
- 英語版も独自の訳文であり、言語間の測定の同等性は未検証です。
- メモ本文は翻訳せず、そのままコピー・共有・印刷に含めます。
- 両言語の全9段階の判定、40問の英訳、英語の結果文に日本語が残らないことをNode.jsで確認。
- ブラウザで日英の切替、英語40問の完了、結果表示、英語とメモのコピー、再開始時の言語保持を確認。
